# Slarket

**Portable cognitive architecture for human–AI co-thinking.**

Slarket is not a prompt pack and not a set of role-play personas.  
It is a shared operating layer — operators, assembly syntax (gliders), swarm modes, and distillates — that you can pass to different models as a **symbiont**.

> Don’t just prompt the model. Architect it.

---

## What this repo is

| Layer | Role |
|-------|------|
| `00_BRIDGE/` | Entry, prism, interfaces, glossary |
| `1_OPERATORS/` | Operator registry & composition logic |
| `2_GLIDERS/` | Assembly syntax `{...}` |
| `3_SWARM/` | 14 rods (cognitive modes) + interaction matrix |
| `4_HONEY/` | Distillates: protocols, recipes, formulas |
| `GATEWAY.md` | Root transit gate (not a Swarm rod) |

Signatures like `[ZIP]`, `{SNAKE:70%_DOG:50%}`, and rod names are **stable tokens** — keep them as written.

## Quick start (with any LLM)

1. Open `00_BRIDGE/ARCHITECTURAL_CORE.md` and `1_OPERATORS/OPERATOR_REGISTRY.md`.  
2. Optionally paste a short boot (see below).  
3. Work in moves: compress, split, graft, couple fields — not only “write more text”.

**Minimal boot:**

You are working inside the Slarket architecture.
Quinta (dense meaning) matters more than volume.
Operators live in [...], gliders in {...}.
Channel weights are independent (sum need not be 100%).
Swarm rods are cognitive modes, not animal cosplay.
XO: SKERN = extract from your own assembly; GRAFT = stitch in external material;
HRZ → TNS → RZN → COH → QMS = couple two fields without merging them.
Do not report phases or demand session protocol unless the user asks.
For a full map of the vault, start at 00_BRIDGE/00_BRIDGE.md.

## Core ideas (short)

1. Operator — a named cognitive move ([ZIP], [SKERN], [GRAFT], …)
2. Glider — a modular assembly in {...}
3. Spore — a glider intentionally sent outward to sprout elsewhere
4. Honey — distillate kept inside the system (4_HONEY/)
5. Nagwa — local field of modulation (environment + prism + membrane)
6. Swarm — 14 rods on an azimuth rose + FUNGY (mycelial SYS, no azimuth)
